# surya.narada.systems

Surya — a Narada family research program for alternative space-grade solar
energy. Offshoot of [space.narada.systems](https://space.narada.systems);
founding document: the
[research directions](https://space.narada.systems/articles/research-directions-space-solar/)
article (R1–R7), with a published kill table per the family epistemic
contract.

Static Astro site deployed to Cloudflare Workers.

```bash
npm install
npm run dev      # local
npm run build    # build
npm run ship     # build + wrangler deploy
```

The name: Marici is the light before the source; Surya is the source.
